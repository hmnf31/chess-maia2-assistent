What Is Maia-2?

Maia-2 (NeurIPS 2024) is a neural network trained on millions of human chess games. Unlike Stockfish or LC0 that search for the mathematically strongest move, Maia-2 predicts the move a human would actually play at a given rating level.

🎯

ELO-Based Predictions

Adjusts to any skill level from 800 to 3500 — the same position gets different moves for different ratings

Engine Features

Beyond raw prediction — layers that simulate realistic human behavior

PERSONA
👤

6 Unique Personas

From Beginner (1200) to Master (2400), each with custom ELO, temperature, style, and behavioral flags.

EMOTION
😤

Emotion State Machine

Mood changes during play: calm → confident → pressured → frustrated → tired → aggressive. Affects move selection.

FATIGUE
😩

Fatigue System

After 40 moves, accuracy degrades. Longer games = more mistakes, just like human players.

STYLE
🎨

Style Biasing

Each persona prefers a play style — aggressive, positional, solid, technical, or universal (no bias).

STOCHASTIC
🎲

Stochastic Sampling

Moves are sampled from the probability distribution, not always the top move. Temperature controls randomness.

REPERTOIRE
📖

Transposition Table

The same position always gets the same response — simulating a player's learned repertoire.

How To Use

Two ways to use — pick the one that suits you

1

Install Extension

Download the extension folder, go to chrome://extensions, enable Developer mode, click Load unpacked, and select the extension folder.

2

Open Chess.com or Lichess

The extension automatically connects to the online server at https://hmnf31-maia2online.hf.space. No Python or server setup needed.

3

Select Persona & Play

Click the extension icon to choose your persona, adjust ELO, and toggle features. Green arrows appear on the board showing the best moves.

1

Install Python & Dependencies

Requires Python 3.10+. Run: pip install -r requirements.txt

2

Start the Server

Run python server.py or double-click jalankan_server.bat. The server starts at http://127.0.0.1:5000.

3

Load Extension & Switch URL

Load the extension from the extension folder. In the popup, change server URL to http://127.0.0.1:5000, click Test, then Save.

Chrome Extension Features

Visual hints directly on Chess.com and Lichess boards

Multi-Line Analysis

Top 5 moves shown with colored arrows — best move in green, others in blue/orange/purple/gray with probability percentages.

📊

Eval Bar

Real-time win probability bar displayed next to the board, like Stockfish evaluation but based on human prediction.

🚨

Blunder Detection

Instant popup warning when your move deviates significantly from the recommended human move.

After the game ends, automatic analysis shows accuracy percentage, blunder count, and dominant mood.
